# 이은우 — 나를 소개하는 한 페이지

수업 과제용 개인 소개 사이트입니다.

## 파일
- `index.html` : 페이지 본문
- `style.css` : 디자인과 반응형 레이아웃
- `script.js` : 카드 클릭/키보드 상호작용

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## 과제 검사 포인트
- 1366×768 / 1920×1080에서 핵심 내용 확인
- 링크와 버튼 직접 확인
- Tab → Enter/Space로 상호작용 확인
- 작은 화면에서 가로 스크롤/잘림 확인
- 실제 발견한 결함 3개를 수정 전/후로 기록
- AI에게 맡긴 판단과 직접 판단한 내용을 별도로 기록

※ 사진은 넣지 않은 버전입니다.
